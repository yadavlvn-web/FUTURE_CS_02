# Phishing Email Detection and Awareness

## Project Overview

This project is part of the Future Interns Cyber Security Internship. It focuses on identifying suspicious emails and understanding common phishing indicators.

## Objectives

* Understand how phishing emails work.
* Identify suspicious email characteristics.
* Compare suspicious and normal-looking email samples.
* Recommend safe practices to prevent phishing attacks.

## Project Structure

* `samples/` — Contains fictional email samples for practice.
* `report/` — Contains email analysis and comparison reports.
* `screenshots/` — Contains project screenshots and evidence.

## Tools Used

* GitHub for project documentation.
* Text editor for creating sample emails and reports.
* Manual analysis of email content.

## Key Findings

Common phishing indicators include:

* Urgent or threatening language.
* Suspicious links.
* Requests for sensitive information.
* Unverified sender identities.

## Safety Recommendations

* Do not click suspicious links.
* Never share passwords or banking details through suspicious emails.
* Verify messages through official websites or apps.
* Report suspected phishing emails.

## Disclaimer

All email samples in this project are fictional and created for educational purposes. No real accounts, emails, or systems were tested.
