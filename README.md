# Phishing Email Detection and Awareness System

## Project Overview

This project focuses on identifying suspicious emails and understanding common phishing indicators. It was created as part of the Future Interns Cyber Security Internship.

## Objectives

* Identify common phishing indicators.
* Analyze suspicious email content.
* Compare phishing and normal-looking email samples.
* Promote email security awareness.

## Project Structure

* `samples/` – Fictional email samples for practice.
* `report/` – Email analysis and comparison reports.
* `screenshots/` – Project screenshots and evidence.

## Tools Used

* GitHub
* Text editor
* Manual email content analysis

## Key Phishing Indicators

* Urgent or threatening language.
* Suspicious links.
* Requests for sensitive information.
* Unverified sender identity.

## Safety Recommendations

* Avoid clicking suspicious links.
* Never share passwords or banking details in response to suspicious emails.
* Verify messages through official websites or apps.
* Report suspected phishing emails.

## Disclaimer

All email samples in this project are fictional and intended for educational purposes. No real emails, accounts, or systems were tested.
